# Contributing to Eclipse Shell

Thanks for your interest in improving Eclipse Shell.
This document explains how to contribute cleanly and quickly.

---

## Ways to Contribute

- **Report bugs** — open an issue with steps to reproduce
- **Suggest features** — open an issue with the `feature-request` label
- **Submit code** — fork, branch, PR
- **Improve docs** — README, this file, comments in code
- **Share** — post screenshots, tell friends, star the repo

---

## Reporting a Bug

Include:
1. **What you did** — the exact command you ran
2. **What happened** — the full error traceback or wrong output
3. **What you expected** — what should have happened
4. **Your environment** — OS, Python version, terminal (Windows Terminal? bash? IDLE?)

The more info, the faster it gets fixed.

---

## Suggesting a Feature

Include:
1. **What command?** — name it, e.g. `findsong`
2. **What does it do?** — one-line description
3. **Usage** — how would someone run it? e.g `findsong <query>`
4. **Why useful?** — what problem does it solve?

If it fits the roadmap, it gets built.
